# 📚 Proof of Escape – Frontend Documentation

This folder (`/docs`) contains the static frontend files used to interact with the Proof of Escape smart contracts. It is designed to be served via GitHub Pages or any simple web server.

---

## 📁 Folder Structure

```
docs/
├── abi/                # ABI files for interacting with deployed contracts
├── assets/             # Static assets (images, sounds, etc.)
│   └── sounds/
├── data/               # Quiz data and metadata for NFTs
├── js/                 # JavaScript logic for interacting with contracts
├── style.css           # Global styling
├── index.html          # Entry point of the DApp
└── README.md           # You're here
```

---

## 🔧 Main Components

### `index.html`
Main interface for the DApp. Contains:
- Wallet connection
- Quiz registration and selection
- Hash generation and submission
- NFT minting section

### `js/` folder
Modular JS files handling key functionality and network integration:
- `wallet.js` – Connects MetaMask and manages user session
- `quiz.js` – Loads quiz list and logic gating
- `hash.js` – Generates SHA256 hash and auto-copies to clipboard
- `submit.js` – Submits answers to the smart contract
- `mint.js` – Interacts with the NFT minting contract
- `leaderboard.js` – Displays registered users and completions
- `admin.js` – Admin tools (e.g., set quiz hash)
- `config.js` – Holds contract addresses and URLs
- `network.js` – Detects and adds the correct Besu network to MetaMask if missing
- `utils.js` – Helper functions
- `main.js` – Orchestrates UI and event logic

---

## 📦 ABI and Data

- `abi/` – Contains the contract ABIs generated by Foundry or Hardhat.
- `data/` – Includes:
  - `quizzes.json` – Quiz content (ID, title, hash, hint, reward)
  - `poe-nft.json` – Metadata template for the reward NFT

---

## 🎨 Styling

- `style.css` – Central CSS file. Includes:
  - Quiz and form layouts
  - Custom button states
  - Success/failure messages
  - NFT celebration animation styling

---

## 🛠 How to Use Locally

To test the frontend locally:

1. Serve the `docs/` folder using a simple HTTP server:
   ```bash
   cd docs
   python3 -m http.server
   ```

2. Open the browser at [http://localhost:8000](http://localhost:8000)

> ⚠️ Make sure MetaMask is connected to the correct network (e.g., Besu private chain) and the contracts are deployed at the addresses defined in `config.js`.

---

## 🔐 Notes

- No build tool (e.g., Webpack) is required — everything is plain HTML/JS/CSS.
- The app is designed for self-contained use and can run from GitHub Pages or IPFS.
- Add sounds/images/fonts in the `assets/` folder as needed.
